# Store listing: English

Copy-ready text for Chrome Web Store. This file does not indicate that the extension has been published. See the [publishing guide](README.md) for assets and privacy information.

## Name

x-reader

## Short description

An automatic table of contents for long reads on X. Jump to headings and navigate chapters with the arrow keys.

## Detailed description

Find your place in long articles on X without repeatedly scrolling to locate a heading. x-reader builds a table of contents from the content already loaded on the page, helping you understand the structure and jump to the section you want to read.

Features:

- Automatic outlines for X/Twitter post detail pages and Articles, using semantic headings, standalone bold lines and numbered section titles.
- Click a chapter to highlight it immediately while the article scrolls to the corresponding heading.
- Use Up and Down to move between chapters when the outline is open. Input fields retain their normal keyboard behavior.
- Use the right sidebar for the outline, and drag either the expanded panel or its collapsed icon to reposition it.
- Follow the page theme, or choose light or dark colors.
- Update the outline automatically when article content changes.
- Process article content locally in the current page. Preferences stay in the current browser. No article uploads. Anonymous popup analytics is off by default and requires explicit opt-in.

Getting started:

1. Refresh X tabs that were open before installation.
2. Open a post detail page or article that contains section headings and expand the full text.
3. Click a chapter in the outline, or use Up and Down to navigate.
4. Open the toolbar popup to adjust heading detection, change the theme or disable the outline.

Please note:

- Only already-loaded content can be recognized. Short posts without headings and home feeds do not receive an automatic outline.
- Bold and numbered heading detection uses heuristics and may miss or misidentify headings. Either detection mode can be disabled.
- No additional extension account or API key is required. X's own login and access requirements still apply.
- x-reader is an independent open-source project and is not affiliated with X.

Source code and support: https://github.com/alexwjj/x-reader

## Single purpose

Generate a local table of contents from already-loaded headings on X/Twitter post detail pages and Articles, so readers can preview the structure and navigate between sections.
